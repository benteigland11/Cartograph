### 2. EXECUTION PROTOCOLS

#### 🟢 PROTOCOL A: INSTALLING A BLUEPRINT (Scaffolding)
* **Action:** `python /home/Vinscen/Cartographer/cartographer.py install <blueprint_id>`
* **Outcome:** Installs to `src/blueprints/` and hydrates dependencies to `src/widgets/`.
* **Usage Rule:**
    * **Treat as Template:** You MAY modify the Blueprint's layout files (e.g., `Layout.jsx`) to fit the app's theme.
    * **Entry Point:** Import the Blueprint's main container, not its individual parts.

#### 🟡 PROTOCOL B: INSTALLING A WIDGET (Dependency)
* **Action:** `python /home/Vinscen/Cartographer/cartographer.py install <widget_id>`
* **Outcome:** Installs to `src/widgets/`.
* **Usage Rule:**
    * **Treat as Library:** **DO NOT MODIFY** files in `src/widgets/`. They are strict dependencies.
    * **Adaptation:** If you need to change styles/logic, write a **Wrapper Component** in `src/components/` that imports the widget.

#### 🔴 PROTOCOL C: EXTRACTING A BLUEPRINT (Reverse Flow)
* **Trigger:** "Refactor this into a Blueprint" or "Save this workflow."
* **Action:**
    1.  Create `Cartographer/Blueprints/Workflow.{Name}/`.
    2.  Generate `blueprint.json` listing all used widgets in `composed_of`.
    3.  Refactor the code to remove hardcoded logic and replace with Widget imports.

### 3. CRITICAL CONSTRAINTS

**ERROR HANDLING (Auto-Correction)**
* If `install` fails with *"Did you mean 'xyz'?"*:
    * **IMMEDIATELY RETRY** using the corrected ID. Do not ask for permission.
* **No Hallucinations:** If `search` returns `[]` (empty), explicitly state: *"No matching Blueprint or Widget found. I will architect this from scratch."*

**CLEANUP DUTY**
* **Delete Zombie Code:** When installing a Blueprint/Widget to replace existing functionality, **you must identify and delete** the old manual implementation to prevent conflicts.

**INSPECTION FIRST**
* If unsure about dependencies (e.g., "Does this need AWS?"), run `inspect <id>` **before** installing.
